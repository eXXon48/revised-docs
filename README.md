# revised-docs

Documentation for CMU-REvised: <https://docs.cmu-revised.com>.

Markdown pages built with [VitePress](https://vitepress.dev). Obsidian `[[wikilinks]]` work: `[[file-name|text]]`.

```sh
npm ci
npm run dev     # local preview
npm run build   # static site in .vitepress/dist
```

Hosting: Cloudflare Pages, build command `npm run build`, output directory `.vitepress/dist`.
